# Week 13a - React and Props Map
## ICS 385 Spring 2026 | April Hope

### What is it? 
This is a small React app that renders a grid of Hawaii island cards that can be filtered using Props, .map(), .filter(), and .reduce(). All the data for the islands is in App.jsx, going from IslandList to IslandCard via props. This mirrors what I will be using in my Term Project dashboard in future work. 

### Features
- IslandCard has no hard-coded values inside the child
- IslandList renders cards via .map() with unique key props
- THe Dropdown menu filters by visior segment using useState + .filter()
- I did take inspiration from my Hale 'Ohi'a Lehua term project volcanic palette for the page CSS 

### Featured Islands
1. Maui - Honeymooners
2. O'ahu - First-timers
3. Kaua'i - Eco-tourists 
4. Hawai'i - Adventure
5. Moloka'i - Cultural (this was my custom addition)
