# Week 6 - Assignment 6a - To Do List Update

This project is a basic Express app that creates two separate to-do lists:

- **/chores**
- **/camping**

Each route has a preset array of three items. New items can be added via form submission. 

## How it works

- root route (`/`) redirects to (`chores`)
- each route uses the same EJS template for display
- items are stored in separate arrays and updated based on the route submission. 

## Runs Locally on Port 3000
npm install
node index.js

This code is based off of instructor-provided code and modified to meet the assignment requirements.
