# Week 6 - 6b Random Course Generator

**Name** April Hope
**Date** 02/20/26

## Description
This is an Express and EJS application that generates a random UHMC course by combining a random Course ID and Course Name from provided arrays when the user clicks the "Generate Course" button.

## How It Works 
- Express handles routing 
- EJS renders dynamic HTML
- Course IDs and Names stored within arrays
- Math.random() selects a random combination 
- The page reloads and displays the generated result 

## Runs Locally 
on http://localhost:3000
