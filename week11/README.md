# Week 11 - PyMongo and MongoDB CRUD Assignment

A Python script that demonstrates the CRUD operations. Creates a 'Customer' collection in the 'ics385_week11' database and performs the following operations: 

- Delete All - to clear the collection for a fresh start
- Insert Many - to add 3 customer records with firstname, lastname, email, and phone number
- Update - updates one of the customer's emails and another's phone number
- Query - looks up one customer by last name and another one by first name
- Drop - removes the entire collection at the end
