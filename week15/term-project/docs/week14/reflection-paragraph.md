One challenge I ran into was a CommonJS vs ES module conflict. When I copied forward my week13 work, I had "type": "module" in the package.json because Vite/React usesrequires ES modules. However, since I didn't explicitly tell Express/Node to use ES modules as well, there was a ReferenceError being thrown since it defaults to CommonJS. To fix this I restructured my project, separating my React frontend from my Express backend by putting React into into the client/ folder with it's own package.json, and leaving the Express backend with it's own separate root-level package.json.
