bcrypt protects passwords by never storing any actual passwords in the database. Instead only hashed version are stored. This way, when a user registeres bcrypt takes the password, adds a random "salt" (as we discussed in class) and then runs it through an algorithm to turn it into a secure code. This way, even if the database is compromised, the hashed passwords are still not usable by the intruder. This helps protect against things like brute-force attacks.
