### File Descriptions

**index.html**
Provides the main webpage structure for the course catalog. 

**styles.css**
Styling and responsive layout for the course cards.

**course-catalogue.js**
Loads JSON data, creates the course cards, and handles the search and filtering functions. 

**sample-data.json**
Contains the course catalog information including departments, courses, instructors, and topics. 

## How to Run

1. Open the project folder in **VS Code** 
2. Start with **Live Preview** if possible 
3. Open `index.html` in the browser window. 
4. Use the search box or the department filter to search through courses using specific keywords.
