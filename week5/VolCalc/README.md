# Volume of Cylinder Calculator (Week5 Assignment 5c)

This is an Express.js web app that is based off debasisb BMICalculator, updated and edited to calculate the volume of a cylinder given it's height and radius

## Features and Forumla Used

This app uses java math functions to calcuate the following equation: 

volume = pi * (r^2) * h

java math functions used to achieve this are: 
- Math.pi
- Math.pow()

also added the .toFixed(2) to limit the resulting number to 2 decimal places
