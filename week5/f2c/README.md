# Fahrenheit to Centigrade converter assignment (week 5b assignment)

This project is a simple Express web app that converts a temperature given in Fahrenheit into Centigarde. Based off debasisb BMICalculator.html 

## Features
- Uses Express
- Accepts integer Fahrenheit input
- Retuns Centigrade temperature as an integer 

## Formula Used 
(F - 32) * 5 / 9
