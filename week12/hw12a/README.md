# HW12A: React Basics Assigment

A small multi-component React application built with Vite. 

The app renders three Hawaiian Island Cards, one each for Maui, Oahu, and Kaua'i. Each card displays an island name, a one-sentence description, and a visitor tip. Components are organized across two files: [App.jsx](week12/hw12a/src/App.jsx) and [IslandCard.jsx](week12/hw12a/src/components/IslandCard.jsx) using ES6 import/export syntax. Island data is stored as an array in App.jsx and rendered using .map().
